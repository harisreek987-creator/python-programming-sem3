# TechHub Mobile Accessories Billing System
**Module I | Individual Python mini-project**

A console-based billing application for a mobile accessories store.

## Features
- Product catalogue with eight accessories and customer input validation
- Multiple products in one cart with quantity selection
- Subtotal and conditional 5% discount for bills of ₹5,000 or more
- 18% GST calculated after discount
- Cash, UPI and card payment selection
- Random bill number, date/time and formatted receipt
- Receipt saved to a text file

## Python concepts
Functions, dictionaries, lists, loops, input validation, exception handling, file handling, `datetime` and `random`.

## Run
```bash
python billing_system.py
```
